# Card Store 単体テスト仕様書

## 目的

取得済みカードの変更と消去が参照結果に反映され、参照可能なデックに属する同じ所有者のカードだけを取得できることを確認する。保存した変更を取得するまでの状態と、保存に失敗したときに維持される内容も確認する。Firestore document の検証、実際の保存・通信、購読の停止は扱わない。

関連 E2E: [CARD-VIEW-01](../../e2e/card-view.md#card-view-01)、[ACCOUNT-04](../../e2e/account.md#account-04)

共通の検証前提は [AGENTS.md](./AGENTS.md) を参照する。

### UNIT-STORE-CARD-01 [TODO] 最新の取得結果だけをカード一覧として提供する

カテゴリ: `state-change`

区分: 正常系

Given:

入力カードの所属デックと所有者は参照可能なデックと一致している。各行を独立して検証する。

| 変更前のカード | 新しい取得結果 |
| --- | --- |
| なし | A、B |
| A（表面が旧内容）、B | A（表面が新内容）、C |
| A、B | なし |

When:

新しい取得結果をカードモデルへ反映する。

Then:

参照できるカードの ID と内容は新しい取得結果に一致する。以前だけ存在した B や A の旧内容は残らず、空の結果を受け取った場合は以前のカードを参照できない。

<a id="unit-store-card-02"></a>

### UNIT-STORE-CARD-02 [TODO] カードのクリア後は以前のカードを参照できない

カテゴリ: `scope-reset`

区分: 正常系

Given:

参照可能なデックに属するカード A、B を保持している場合と、カードを保持していない場合を用意する。

When:

カードモデルのクリア操作を行う。

Then:

どちらの場合もカード一覧は空となり、以前のカードを参照できない。既に空であっても操作は失敗しない。

<a id="unit-store-card-03"></a>

### UNIT-STORE-CARD-03 [TODO] 所属デックと所有者が一致するカードだけを提供する

カテゴリ: `visibility`

区分: 正常系

Given:

カード A はデック X・利用者 a、カード B はデック X・利用者 b、カード C はデック Y・利用者 a に属する。カードを保持したまま、参照可能デックを次の各条件にする。

| 参照可能なデック | 取得できるカード |
| --- | --- |
| デック X・利用者 a | A のみ |
| デック X・利用者 b | B のみ |
| なし | なし |

When:

現在のカード一覧を取得する。

Then:

結果は表に一致する。デック ID だけが一致する別所有者のカードや、参照できるデックのないカードは含まれない。

<a id="unit-store-card-04"></a>

### UNIT-STORE-CARD-04 [TODO] カードの作成・編集・削除を最新の取得結果に合わせて反映する

カテゴリ: `state-change`

区分: 正常系

Given:

対象カードと対象外のカード B は、本人の参照可能なデックに属する。本人のカード一覧を取得済みである。対象外の B は表面・裏面の本文とタグを標準値から変更済みである。各行を独立した状態とする。

| 操作 | 操作前の一覧 | 変更を取得した後の一覧 |
| --- | --- | --- |
| A を作成 | B のみ | 指定した内容の A と既存の B |
| A を編集 | 変更前の A と B | 変更後の A と既存の B |
| A を削除 | A と B | B のみ |

When:

表の操作を行う。操作が受け付けられ、保存が完了した後もしばらく変更後の一覧を取得できず、その後に最新の一覧を取得する。

Then:

変更後の一覧を取得するまでは、操作が受け付けられた後も保存が完了した後も一覧が操作前と一致する。取得後は作成した A が現れ、編集した A の表面・裏面の本文とタグが更新され、削除した A は参照できなくなる。すべての時点で B の ID と内容を維持し、A の重複や古い編集内容は残らない。

### UNIT-STORE-CARD-05 [TODO] カードの保存に失敗しても取得済みのカードを維持する

カテゴリ: `state-change`

区分: 異常系

Given:

対象カードと対象外のカード B は、本人の参照可能なデックに属する。本人の B を取得済みで、表面・裏面の本文とタグを標準値から変更している。各行を独立して用意する。

| 操作 | 操作前の A | 失敗後の A |
| --- | --- | --- |
| 新規作成 | 存在しない | 存在しない |
| 編集 | B とは異なる変更済みの内容で取得済み | 操作前の内容のまま |
| 削除 | B とは異なる変更済みの内容で取得済み | 操作前の内容のまま |

When:

指定した操作が受け付けられた後、その変更の保存に失敗する。変更後の内容は取得していない。

Then:

A の有無と内容は表に一致し、B の ID と表面・裏面の本文とタグは操作前と一致する。作成対象の追加、編集内容への置き換え、削除対象の除外、一覧全体の消去を行わない。
