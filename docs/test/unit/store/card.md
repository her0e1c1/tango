# Card Store 単体テスト仕様書

## 目的

取得済みカードの変更と消去が参照結果に反映され、参照可能なデックに属する同じ所有者のカードだけを取得できることを確認する。書き込みの受付・成功・失敗と購読通知を分け、通知前には参照結果を直接変更しないことも確認する。Firestore document の検証、実際の保存・通信、購読の停止は扱わない。

関連 E2E: [CARD-VIEW-01](../../e2e/card-view.md#card-view-01)、[ACCOUNT-04](../../e2e/account.md#account-04)

共通の検証前提は [AGENTS.md](./AGENTS.md) を参照する。

### UNIT-STORE-CARD-01 [TODO] 最新の取得結果だけをカード一覧として提供する

カテゴリ: `state-change`

区分: 正常系

Given:

入力カードの所属デックと所有者は参照可能なデックと一致している。各行を独立して検証する。

| 変更前のカード | 新しい取得結果 |
| --- | --- |
| なし | A、B |
| A（表面が旧内容）、B | A（表面が新内容）、C |
| A、B | なし |

When:

新しい取得結果をカードモデルへ反映する。

Then:

参照できるカードの ID と内容は新しい取得結果に一致する。以前だけ存在した B や A の旧内容は残らず、空の結果を受け取った場合は以前のカードを参照できない。

### UNIT-STORE-CARD-02 [TODO] カードのクリア後は以前のカードを参照できない

カテゴリ: `scope-reset`

区分: 正常系

Given:

参照可能なデックに属するカード A、B を保持している場合と、カードを保持していない場合を用意する。

When:

カードモデルのクリア操作を行う。

Then:

どちらの場合もカード一覧は空となり、以前のカードを参照できない。既に空であっても操作は失敗しない。

<a id="unit-store-card-03"></a>

### UNIT-STORE-CARD-03 [TODO] 所属デックと所有者が一致するカードだけを提供する

カテゴリ: `visibility`

区分: 正常系

Given:

カード A はデック X・利用者 a、カード B はデック X・利用者 b、カード C はデック Y・利用者 a に属する。カードを保持したまま、参照可能デックを次の各条件にする。

| 参照可能なデック | 取得できるカード |
| --- | --- |
| デック X・利用者 a | A のみ |
| デック X・利用者 b | B のみ |
| なし | なし |

When:

現在のカード一覧を取得する。

Then:

結果は表に一致する。デック ID だけが一致する別所有者のカードや、参照できるデックのないカードは含まれない。

<a id="unit-store-card-04"></a>

### UNIT-STORE-CARD-04 [TODO] カードの作成・編集・削除は書き込み完了ではなく購読通知で反映する

カテゴリ: `state-change`

区分: 正常系

Given:

対象カードと対象外のカード B は、本人の参照可能なデックに属する。本人のカードを購読している。対象外の B は表面・裏面の本文とタグを標準値から変更済みである。各行を独立した状態とする。

| 操作 | 操作前 | 後から届く取得結果 |
| --- | --- | --- |
| A を作成 | B のみ | 指定した内容の A と既存の B |
| A を編集 | 変更前の A と B | 変更後の A と既存の B |
| A を削除 | 未削除の A と B | 削除日時が付いた A と既存の B |

When:

表の公開操作を行い、購読通知がまだない時点で操作の受付後と SDK の書き込み成功後の状態をそれぞれ参照する。その後、表の取得結果が購読へ届く。

Then:

購読通知前は、操作の受付後も書き込み成功後も参照結果が操作前と一致する。通知後は作成した A が現れ、編集した A の表面・裏面の本文とタグが更新され、削除した A は参照できなくなる。すべての時点で B の ID と内容を維持し、A の重複や古い編集内容は残らない。これは通知前後の状態を保証し、保存の成功や SDK の通知生成自体は保証しない。

<a id="unit-store-card-05"></a>

### UNIT-STORE-CARD-05 [TODO] カードの書き込み失敗だけでは直前の購読結果を変更しない

カテゴリ: `state-change`

区分: 異常系

Given:

対象カードと対象外のカード B は、本人の参照可能なデックに属する。本人の B を取得済みで、表面・裏面の本文とタグを標準値から変更している。各行を独立して用意する。

| 操作 | 操作前の A | 失敗後の A |
| --- | --- | --- |
| 新規作成 | 存在しない | 存在しない |
| 編集 | B とは異なる変更済みの内容で取得済み | 操作前の内容のまま |
| 削除 | B とは異なる変更済みの内容で取得済み | 操作前の内容のまま |

When:

公開操作が受け付けられた後、SDK の書き込みが失敗する。新しい取得結果は届かない。

Then:

A の有無と内容は表に一致し、B の ID と表面・裏面の本文とタグは操作前と一致する。作成対象の追加、編集内容への置き換え、削除対象の除外、一覧全体の消去を行わない。エラー表示や再試行はこのケースの対象外とする。
