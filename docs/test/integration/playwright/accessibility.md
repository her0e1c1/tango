# 表示部品のアクセシビリティ Playwright テスト仕様書

## 目的

実際の store から操作する画面の最終状態と、表示・ドキュメント用の部品例をブラウザーに描画し、表示状態ごとのアクセシビリティを確認する。画面の操作や store の状態遷移は各画面の仕様で確認する。

### PLAYWRIGHT-ACCESSIBILITY-01 [TODO] 表示例にアクセシビリティ違反がない

カテゴリ: `render`

区分: 正常系

Given:

- 画面結合テストで操作と確認を完了した各状態、および表示・ドキュメント用の部品例を対象とする。後者は公式の公開インデックスから取得し、テスト対象として公開された全例を独立した入力例とする。
- 各例の args、decorator、表示言語、明暗テーマ、画面幅、表示状態の準備と、宣言済みのアクセシビリティ設定を適用する。

When:

- 画面の操作・確認、または描画と表示状態の準備が完了した後、本文全体を axe で確認する。

Then:

- アクセシビリティ違反を残さず、描画時の未処理エラーや予期しない外部通信もない。
- 部品例には画面全体のランドマークが揃わないため region の規則を適用しない。複数の設定フォームを併置する例では、宣言済みの landmark-unique の例外も維持する。他の規則や重大度を一括で除外しない。
- 例ごとの描画失敗や未対応の検証設定を成功として扱わない。
