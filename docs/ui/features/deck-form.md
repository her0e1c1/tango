# DeckForm

作成・編集フォームの表示と入力。Story側でフォーム値、エラー、送信待機、編集時の追加領域を準備する。保存や削除の成功は扱わない。

Storybook: `Features/Deck Form/DeckForm`。

[コンポーネント](../../../src/features/deck-form/ui/DeckForm.tsx) / [Story](../../../src/features/deck-form/ui/DeckForm.stories.tsx) / [一覧・共通前提](../README.md)

## Story仕様

| Story | 入力・表示条件 | 期待する表示・操作 |
| --- | --- | --- |
| `Create` | 空の名前とカテゴリで作成モードにする。 | 作成用の入力欄と操作を表示する。 |
| `Edit` | 保存済みの名前・カテゴリ・URLとデッキ情報を渡す。 | 編集値、デッキ情報、Storyから渡した削除案内の領域を表示する。 |
| `ValidationError` | 名前とURLのエラーをフォームに渡す。 | エラーと対象の入力欄を表示し、URLエラーを折り畳み内に隠さない。 |
| `Creating` | 作成フォームの送信を待機させる。 | 作成中の表示になり、再送信できない。 |
| `Saving` | 編集フォームの送信を待機させる。 | 保存中の表示になり、再送信できない。 |
| `LongContent` | 長い名前とURLを持つ編集値を渡す。 | 入力値と追加情報が操作領域を押し出さない。 |
| `Interaction` | 名前・カテゴリ、詳細設定のURL・改行変換を編集し、詳細を閉じて開く。 | 入力値と選択を保持する。 |
| `Mobile` | 狭い画面で長い編集値を表示する。 | 入力欄と操作を画面幅内で確認できる。 |
| `Dark` | 暗いテーマで長い編集値を表示する。 | 入力欄、補足情報、操作を判別できる。 |
| `MobileCreate` | 狭い画面で空の作成フォームを表示する。 | 作成用の入力欄と操作を確認できる。 |
| `ExpandedSettings` | 詳細設定を開いた状態を準備する。 | URLと改行変換の入力を確認できる。準備だけの play を検証済みとは扱わない。 |
| `JapaneseMobileCreate` | 日本語かつ狭い画面で作成モードにする。 | 日本語のラベルと操作が画面幅内に収まる。 |
