# CardPlayer

表裏の表示領域、操作パネル、閲覧モード、ヘルプと入力の通知。表示内容と状態はpropsやスロットで準備し、学習の進行・保存・ルート遷移は扱わない。

Storybook: `Features/Card Player/CardPlayer`。

[コンポーネント](../../../src/features/card-player/ui/CardPlayer.tsx) / [Story](../../../src/features/card-player/ui/CardPlayer.stories.tsx) / [一覧・共通前提](../README.md)

## Story仕様

| Story | 入力・表示条件 | 期待する表示・操作 |
| --- | --- | --- |
| `Default` | 通常の表面、補足情報、方向ボタン、再生操作を渡す。 | 問題文を中央に表示し、指定した操作と情報を表示する。 |
| `HelpOpen` | ヘルプを開いた状態を渡す。 | 操作説明のダイアログを表示する。 |
| `SwipeControlsHidden` | 方向ボタンを非表示にする。 | 方向ボタンを隠しても問題文の中央配置を保つ。 |
| `PlaybackControlsHidden` | 再生操作を非表示にする。 | 再生操作を隠しても問題文の中央配置を保つ。 |
| `CardDetailsHidden` | カードの補足情報を非表示にする。 | 補足情報を隠しても問題文の中央配置を保つ。 |
| `ControlsHidden` | 方向ボタンと再生操作を非表示にする。 | 両方を隠しても問題文の中央配置を保つ。 |
| `PlaybackUnavailable` | 再生操作を利用不可にする。 | 利用不可の表示条件を反映し、問題文の中央配置を保つ。 |
| `LongAnswer` | 長い裏面を表示する。 | 解答領域を表示し、通常の学習操作パネルを表示しない。 |
| `AnswerSwipeOverlays` | 長い裏面に左右の操作領域を渡す。 | 左右の領域を固定表示し、その上のホイールで解答をスクロールできる。クリックは方向を通知する。 |
| `CodeAnswer` | 長いPythonコードを裏面スロットに渡す。 | コードとして解答を表示する。 |
| `MathAnswer` | Markdownと数式を裏面スロットに渡す。 | Markdownと数式として解答を表示する。 |
| `AutoPlay` | 再生中の状態を渡す。 | 再生中に対応した操作を表示する。 |
| `Mobile` | 狭い画面で通常の表面を表示する。 | 問題文の中央配置を保つ。 |
| `Mobile320ActionsOpen` | 320幅の画面で操作パネルを開く。 | 戻る操作と重ならず幅内に収まり、補足情報がパネルに重ならない。 |
| `MobileSafeArea` | 狭い画面で上47・下34のセーフエリアを模擬する。 | 模擬した余白を考慮した位置に問題文を配置する。実端末の検証ではない。 |
| `MobileLongAnswer` | 狭い画面で長い裏面を表示する。 | 解答を読め、通常の学習操作パネルを表示しない。 |
| `Dark` | 暗いテーマで通常の表面を表示する。 | 問題文、補足情報、操作を判別できる。 |
| `DarkCodeAnswer` | 暗色指定の長いコードを裏面に渡す。 | 暗いテーマに合わせたコードを表示する。 |
| `DarkMath` | 暗いテーマで数式とMarkdownを表示する。 | 本文や罫線が周囲の暗いテーマと調和して読める。 |
| `DeckViewing` | 閲覧用の進捗名と左右の移動、上下無効の状態を渡す。 | 閲覧用の表示と移動要求を提供し、受け取った位置を勝手に進めない。 |
| `DeckViewingAnswer` | 閲覧用の長い裏面を表示する。 | 解答をスクロールでき、戻る操作や進捗スライダーを表示しない。 |
| `Japanese` | 通常の表面を日本語で表示する。 | 操作ラベルや説明を日本語で表示する。 |
| `WithActionSlot` | 追加領域にSkipボタンを渡す。 | 渡された追加操作を配置する。 |
| `ViewEditLink` | 編集リンクの表示状態をStory側で切り替える。 | 操作パネル表示中はリンクを隠し、設定に応じて再表示する。閉じると起点にフォーカスを戻す。 |
| `ViewEditLinkNarrow` | 320幅で編集リンクの表示を切り替える。 | 操作同士が重ならず、リンク表示とフォーカス復帰を保つ。 |
| `ViewEditLinkMobile` | モバイル幅で編集リンクの表示を切り替える。 | 操作同士が重ならず、リンク表示とフォーカス復帰を保つ。 |
| `ViewModeLongFront` | 閲覧モードに長い表面を渡す。 | 表面の読書領域にフォーカスし、操作領域と重ならず末尾までスクロールできる。 |
| `ViewModeMobile` | 狭い画面で長い表面を閲覧する。 | 閲覧領域と操作領域を分け、内容を読める。 |
| `ViewModeMath` | 閲覧モードに多数の数式を渡す。 | 数式を読み進められ、閲覧モードの終了を通知できる。 |
| `ReadingSelection` | 閲覧中に本文を選択し、選択あり・なしでクリックする。 | 選択中はモードを切り替えず、選択のない明示的なクリックだけを通知する。 |
| `ReadingSpace` | 閲覧領域でSpaceと本文クリックを行う。 | Spaceで閲覧を終了せず、本文クリックは切替を通知する。 |
| `AnswerChrome` | 裏面と編集リンクを同時に渡す。 | 裏面にフォーカスでき、表面・編集リンク・学習操作・補足情報は表示しない。 |
| `AnswerChromeMobile` | 狭い画面で同じ裏面状態を表示する。 | 裏面だけを読む表示とフォーカス可能な領域を保つ。 |
| `NoEditOperation` | 編集リンクを渡さず操作パネルを開く。 | 編集リンクの表示設定を出さない。 |
| `ToolbarRequests` | 戻る・方向・再生・スキップ・補足情報の操作を行う。 | 対応する要求を通知し、閉じると起点のフォーカスとヘルプ操作を復元する。 |
| `ReadingToggle` | 閲覧モードをStory側で更新する。 | 切替状態と「入る／終了」の説明を現在のモードに合わせる。 |
| `UnavailablePlaybackExplanation` | 間隔0による再生操作の利用不可状態を渡す。 | 操作にフォーカスして理由を読めるが、クリックしても切替要求を通知しない。 |
| `PlaybackOnly` | 方向ボタンだけを隠す。 | 再生操作だけを表示する。 |
| `SwipeOnly` | 再生操作だけを隠す。 | 方向ボタンだけを表示する。 |
| `HelpKeyboardContract` | ヘルプを開き、Tab・Shift+Tab・Escapeで操作する。 | 説明付きのダイアログ内にフォーカスを保ち、閉じるとヘルプ起点に戻す。 |
| `UnstudiedDetails` | 学習情報なしの補足スロットを渡す。 | 未学習を表示し、架空の難易度を表示しない。 |
| `RatedDetails` | 難易度8と固定日時の補足スロットを渡す。 | 受け取った難易度を表示し、未学習の表示を出さない。 |
| `ReadingGestures` | 閲覧中にスワイプ・ドラッグし、方向ボタンも操作する。 | 読書中のジェスチャーを学習要求にせず、明示的なボタン操作だけを通知する。 |
| `AllowedAnswerGestures` | 裏面のクリックと横スワイプを許可する。 | 許可した解答クリック・方向を通知する。 |
| `DisallowedAnswerGestures` | 裏面の横スワイプを許可しない。 | スワイプを通知せず、ドラッグ直後のクリックも別操作として通知しない。 |
| `FrontSwipeWithoutButtons` | 方向ボタンを隠した状態で表面を上へスワイプする。 | ボタンの表示有無とは独立して上方向を通知する。 |
| `FrontMouseGestures` | 表面を中・右・左ボタンでドラッグする。 | 中・右ボタンは無視し、左ドラッグ後のクリックを追加操作にしない。 |
| `RestoreHelpShortcut` | 操作パネルからヘルプボタンを隠して再表示する。 | ヘルプを隠しても表示設定は残り、再表示できる。 |
| `ReadingShortcutVisibility` | 閲覧中に閲覧モードのショートカットを隠して再表示する。 | ショートカット表示だけが変わり、閲覧モード自体を終了しない。 |
| `AllShortcuts` | ヘルプ・閲覧モード・編集リンクをすべて表示する。 | 3つのショートカットと操作パネルの起点を表示する。 |
| `ViewAndEditShortcuts` | 閲覧モードと編集リンクだけを表示する。 | 指定した2つを表示し、ヘルプを表示しない。 |
| `HelpAndViewShortcuts` | ヘルプと閲覧モードだけを表示する。 | 指定した2つを表示し、編集リンクを表示しない。 |
| `ViewShortcut` | 閲覧モードだけを表示する。 | 閲覧モードと操作パネルの起点だけを表示する。 |
| `HelpAndEditShortcuts` | ヘルプと編集リンクだけを表示する。 | 指定した2つを表示し、閲覧モードのショートカットを表示しない。 |
| `NoShortcuts` | 3つのショートカットをすべて隠す。 | 操作パネルの起点は残し、表示設定を操作できる。 |
| `ToggleDetails` | 補足情報の表示をStory側で切り替える。 | 補足情報全体の表示、選択状態、表示・非表示の説明を更新する。 |
