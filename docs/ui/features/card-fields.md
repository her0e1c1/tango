# CardFields

カードの表裏入力、タグ編集、拡大入力とプレビュー。フォームとプレビューをStory側で組み合わせる。送信は入力値の通知までとし、保存は扱わない。

Storybook: `Features/Card Form/CardFields`。

[コンポーネント](../../../src/features/card-form/ui/CardFields.tsx) / [Story](../../../src/features/card-form/ui/CardFields.stories.tsx) / [一覧・共通前提](../README.md)

## Story仕様

| Story | 入力・表示条件 | 期待する表示・操作 |
| --- | --- | --- |
| `Default` | 通常の表裏テキストとタグを渡す。 | 表面の入力と表裏の切替、タグ編集操作を表示する。 |
| `ValidationError` | 表裏の入力エラーを渡す。 | 対象の入力エラーを表示する。 |
| `LongContent` | 長い表裏テキストとタグを渡す。 | 長文とタグが入力領域に収まる。 |
| `Interaction` | 表面を編集して表裏を切り替え、タグを選ぶ。 | 編集した表面とタグの選択を保持する。 |
| `Mobile` | 狭い画面で長文を表示する。 | 入力、切替、タグ編集を画面幅内で確認できる。 |
| `Dark` | 暗いテーマで長文を表示する。 | 入力値・欄の境界・選択タブ・タグ編集操作・フォーカスを判別できる。 |
| `Empty` | 表裏が空でタグもない。 | 空の入力状態を表示する。 |
| `Back` | 裏面タブを開く。 | 裏面の入力とプレビュー操作を表示する。 |
| `Expanded` | 裏面の拡大入力を開く。 | ダイアログ内で裏面を編集できる。 |
| `ExpandedValidationError` | 表裏が空でエラーがある状態から裏面を拡大する。 | 拡大入力でも対象のエラーを確認できる。 |
| `TagSelection` | タグ編集を開く。 | 現在のタグと候補の編集領域を表示する。 |
| `MobileBack` | 狭い画面で長い裏面を開く。 | 裏面の入力と関連操作を確認できる。 |
| `JapaneseValidation` | 日本語で表面エラーを渡す。 | 日本語のエラーを表示し、入力欄の説明として関連付ける。 |
| `Preview` | 数式タグ付きの裏面でプレビューを開く。 | 解答プレビュー領域を表示する。 |
| `MobilePreview` | 狭い画面でプレビューを開く。 | 入力とプレビューを画面幅内で確認できる。 |
| `DarkCodePreview` | 暗色指定と TypeScript タグ付きの裏面を渡す。 | プレビューと入力面の暗色表示をそろえ、コードの本文と強調を読める。 |
| `ExpandedPreview` | 裏面を拡大してプレビューを開く。 | 拡大ダイアログ内にプレビューを表示する。 |
| `ExpandedDraft` | 表面と拡大した裏面を編集して拡大表示を閉じる。 | 両面の下書きを保持し、拡大ボタンにフォーカスを戻す。 |
| `KeyboardTabs` | 矢印、Home、End で表裏タブを操作する。 | 選択タブと入力面が切り替わり、タブのフォーカスが追従する。 |
| `IncompletePreview` | 表面が未入力のまま裏面をプレビューする。 | 未完成の下書きを表示でき、送信や入力エラーを発生させない。 |
| `CustomTagSubmission` | 独自タグを持つ入力でタグを選び直し、閉じて再度開いて送信する。 | 独自タグと追加したタグを保持し、表裏と一緒に通知する。 |
| `BackValidation` | 裏面を空にして送信する。 | 裏面を開いてエラー入力へフォーカスし、拡大時にも同じエラーを説明する。 |
| `PreviewLanguageChange` | 開いたプレビューの言語を日本語に変える。 | プレビューを開いたまま、見出しと操作を翻訳する。 |
| `UnknownErrorLanguage` | 未知のエラーを持つ表面を拡大し、日本語に変える。 | 内部診断を出さず一般的な入力エラーを翻訳し、下書きを保持する。 |
| `CorrectLocalizedDraft` | 日本語に切り替えたエラー入力を拡大して修正し、送信する。 | 裏面とタグを失わず、修正した入力値を通知する。 |
| `ExpandedMathDraft` | 数式カテゴリの裏面を拡大し、Markdown・数式・表を編集する。 | プレビューに編集が反映され、閉じても下書きと他方のエラーを保持する。 |
| `DeckPythonPreview` | Python デッキ、カテゴリタグなし。 | Python のコードとしてプレビューし、テーマ切替を反映する。 |
| `TaggedTypescriptPreview` | 数式デッキに custom・typescript・python の順でタグを渡す。 | 有効な先頭のカテゴリタグを使い、TypeScript の表示とテーマ切替を反映する。 |
| `TaggedMarkdownPreview` | 数式デッキに md タグを渡す。 | md のコード表示を使い、数式表示と混同しない。 |
| `PreviewTagChanges` | 開いたプレビューで Python タグを外し、raw タグを追加する。 | デッキの数式・Markdown表示から通常テキストへ、タグに応じて表示を更新する。 |
| `DirectTagEditing` | タグの名前変更・削除・追加を行い、閉じて再度開く。 | 個別の確定操作なしに下書きを保ち、フォーム送信時にまとめて通知する。 |
| `InvalidTagNames` | 空白のみ、重複、修正済みのタグ名を順に入力する。 | 空白・重複のエラーを説明して送信を止め、修正後は入力値を通知する。 |
