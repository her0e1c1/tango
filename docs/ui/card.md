# Card

カード一覧の1行を表す部品。カード内容、タグ、メニューと利用不可状態を対象にする。

Storybook: `Pages/Card List/Card`。

[コンポーネント](../../src/pages/card-list/ui/Card.tsx) / [Story](../../src/pages/card-list/ui/Card.stories.tsx) / [一覧・共通前提](./README.md)

## Story仕様

| Story | 入力・表示条件 | 期待する表示・操作 |
| --- | --- | --- |
| `Default` | 通常のカードを渡す。 | 表面、タグと行の操作を表示する。 |
| `Unstudied` | 未学習のカードを渡す。 | 学習済みであることを前提にせず行を表示する。 |
| `LongText` | 長い表面を渡す。 | 長文が行の操作を押し出さない。 |
| `LongTags` | 長いタグを持つカードを渡す。 | タグと操作を行の幅内で確認できる。 |
| `ActionsOpen` | 行のメニューを開いた状態を渡す。 | 対象カードの操作メニューを表示する。 |
| `Pending` | 行を無効にする。 | カード閲覧とメニューを操作できない。 |
| `Mobile` | 狭い画面で通常の行を表示する。 | カードと操作を画面幅内で確認できる。 |
| `Dark` | 暗いテーマで通常の行を表示する。 | カード、タグ、操作を判別できる。 |
