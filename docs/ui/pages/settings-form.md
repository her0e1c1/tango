# SettingsForm

設定値、説明、バージョンと設定項目の入力。自動保存の案内表示を含むが、設定の永続化はこのStoryの対象外。

Storybook: `Pages/Settings/SettingsForm`。

[コンポーネント](../../../src/pages/settings/ui/SettingsForm.tsx) / [Story](../../../src/pages/settings/ui/SettingsForm.stories.tsx) / [一覧・共通前提](../README.md)

## Story仕様

| Story | 入力・表示条件 | 期待する表示・操作 |
| --- | --- | --- |
| `Default` | 通常の設定値、バージョン1.2.3、コミット情報を渡す。 | 言語・外観・学習・詳細の設定を表示する。 |
| `Japanese` | 日本語で通常の設定値を表示する。 | 見出しを日本語で表示し、言語の初期選択はSystemのままにする。 |
| `Interaction` | 再生コントロールの表示設定を切り替える。 | フォーム内の選択状態を更新する。 |
| `LongContent` | 長いバージョン文字列を渡す。 | 補足情報が設定や操作を押し出さない。 |
| `Dark` | 暗いテーマで表示する。 | 区分・ラベル・説明・選択値・スイッチとスライダー・フォーカスを判別できる。 |
| `Mobile` | モバイル幅で長いバージョン文字列を表示する。 | 設定と詳細情報を画面幅内で確認できる。 |
| `AllMatchingCards` | 最大カード数0を渡す。 | 0を条件に一致する全カードとして説明する。 |
| `AllMatchingCardsJapaneseMobile` | 同じ最大数0を日本語かつモバイル幅で表示する。 | 全カードの説明を日本語で確認できる。 |
| `SettingsContracts` | 最大24枚、間隔7秒などの設定を渡して編集する。 | 説明と現在値を表示し、編集値をフォームに反映する。アカウント操作を混在させない。 |
| `JapaneseValues` | 最大24枚と間隔7秒の設定を日本語で表示する。 | 項目名と読み上げ用の枚数・秒数を日本語にする。 |
| `MultipleForms` | 同じ設定フォームを2つ表示する。 | 各見出し・説明・ラベルが対応するフォーム内の要素に関連付く。 |
| `MaximumCardsBoundary` | 最大カード数を0・1・2・0と変更する。 | 0〜100の範囲を示し、0は全カード、1・2は枚数として表示・説明する。 |
| `MaximumCardsBoundaryJapanese` | 同じ最大数の変更を日本語で行う。 | 全カードと枚数の表示・説明を日本語で更新する。 |
| `IntervalOffHidden` | 自動再生開始なし、再生操作非表示で間隔を0・1・60秒に変える。 | 0秒の意味と各値を説明し、2つの別設定は変えない。 |
| `IntervalOffVisible` | 自動再生開始なし、再生操作表示で間隔を変える。 | 間隔の表示を更新し、開始なし・表示の設定を保持する。 |
| `IntervalOnHidden` | 自動再生開始あり、再生操作非表示で間隔を変える。 | 間隔の表示を更新し、開始あり・非表示の設定を保持する。 |
| `IntervalOnVisible` | 自動再生開始あり、再生操作表示で間隔を変える。 | 間隔の表示を更新し、開始あり・表示の設定を保持する。 |
| `JapaneseIntervalOffHidden` | 日本語で開始なし・非表示の間隔を0・1・60秒に変える。 | 日本語の秒数と0秒の意味を表示し、別設定を保持する。 |
| `JapaneseIntervalOffVisible` | 日本語で開始なし・表示の間隔を変える。 | 日本語の秒数を表示し、開始なし・表示の設定を保持する。 |
| `JapaneseIntervalOnHidden` | 日本語で開始あり・非表示の間隔を変える。 | 日本語の秒数を表示し、開始あり・非表示の設定を保持する。 |
| `JapaneseIntervalOnVisible` | 日本語で開始あり・表示の間隔を変える。 | 日本語の秒数を表示し、開始あり・表示の設定を保持する。 |
