# CardList

受け取ったカード一覧、件数、空状態、フィルター表示と閲覧領域。抽出・並べ替え計算、保存、画面遷移は対象外。

Storybook: `Pages/Card List/CardList`。

[コンポーネント](../../../src/pages/card-list/ui/CardList.tsx) / [Story](../../../src/pages/card-list/ui/CardList.stories.tsx) / [一覧・共通前提](../README.md)

## Story仕様

| Story | 入力・表示条件 | 期待する表示・操作 |
| --- | --- | --- |
| `Default` | 複数カード、選択タグ2件、標準順とフィルター領域を渡す。 | 一覧、件数、条件と並び順の表示を確認できる。 |
| `AddCard` | カード追加の通知先を渡してActionsから追加を選ぶ。 | カード追加要求を通知する。 |
| `Empty` | カードなしの理由を明示して空配列を渡す。 | 0件、カード未作成の案内と追加操作を表示する。 |
| `FilterZero` | 条件一致なしの理由と選択タグを渡す。 | 条件に一致するカードがないことと条件解除の操作を表示する。 |
| `IntervalZero` | 復習対象なしの理由を渡す。 | 復習対象なしを表示し、条件解除の操作を出さない。理由の判定は利用側の責務。 |
| `ViewCard` | カードの閲覧を操作する。 | 選んだカードIDを通知する。 |
| `RemovableSelectedTags` | 選択タグ2件から1件を解除し、Story側で条件を更新する。 | 解除したタグを通知し、そのタグの表示を消す。 |
| `Long` | 多数・長文のカードとフィルター領域を渡す。 | 長い一覧と条件の収まりを確認できる。 |
| `CardView` | Pythonの裏面を閲覧領域として渡す。 | カード閲覧領域と閉じる操作を表示する。 |
| `DarkCardView` | 暗色の裏面を暗いテーマで渡す。 | 閲覧領域とコードの配色をそろえ、解答と閉じる操作を暗い背景で判別できる。 |
| `CardViewInteraction` | 閲覧領域を閉じ、Story側で表示を解除する。 | 閉じる要求を通知し、閲覧領域を消す。 |
| `Dark` | 暗いテーマで通常の一覧を表示する。 | カード本文・タグ・並び順・行の境界・メニューとフォーカスを判別できる。 |
| `IphoneX` | モバイル幅で通常の一覧を表示する。 | 一覧と条件を画面幅内で確認できる。 |
| `IphoneXLong` | 長いカードと区切りのない長いタグをモバイル幅で渡す。 | タグが画面全体の幅を押し広げない。 |
| `NewestAdded` | 新しい順を渡し、標準順への変更を操作する。 | 選んだ並び順を通知する。実際の並べ替えは保証しない。 |
| `FilterSaving` | フィルター保存中に対応する無効状態と新しい順を渡す。 | 渡された無効状態を反映する。 |
| `CardSaving` | カード操作と並び順を無効にする。 | 並び順を含む指定された操作を行えない。 |
| `UnconfirmedEmpty` | 空配列だけを渡し、空である理由を渡さない。 | 0件と条件を表示するが、未作成だと断定しない。 |
| `LongSelectedTag` | 区切りのない長い選択タグを渡す。 | 選択タグの全文を保持して表示する。 |
| `EmptyAddRequest` | 未作成の案内から追加を操作する。 | 追加要求を通知する。 |
| `EmptyClearRequest` | 条件一致なしの案内から条件解除を操作する。 | 条件解除要求を通知する。 |
| `EditTarget` | タグ付きのカード行から編集を選ぶ。 | タグを表示し、対象のカードIDで編集要求を通知する。 |
| `PendingRow` | 特定のカード行を無効にする。 | その行の閲覧とメニュー起点を無効にする。 |
| `KeyboardTagRemoval` | 選択タグをTabで巡り、Enter・Spaceで順に解除する。 | Tabだけでは解除せず、解除後は残るタグ、最後はフィルター操作へフォーカスを移す。 |
| `RemovedMenu` | 開いたメニューの行を削除して再追加する。 | メニューは1つだけ開き、対象行の削除で閉じ、再追加しても自動で開かない。 |
| `ReorderedView` | 閲覧操作にフォーカスしたまま行順や他の行を更新する。 | フォーカスと閲覧対象のカードIDを維持する。 |
| `ReorderedEdit` | 編集項目にフォーカスしたまま行順や他の行を更新する。 | フォーカスと編集対象のカードIDを維持する。 |
| `Tablet` | 768×1024の画面で長いカード一覧と選択タグ、フィルター領域を表示する。 | 件数・並び順・条件と各行の操作が重ならず、末尾のカードまで読める。 |
| `Desktop` | 1280×800の画面で長い一覧と開いた行メニューを表示する。 | 一覧が広がりすぎず、カードと対象メニューを対応付けて操作できる。 |
| `MobileDark` | 320×568の暗い画面で長い表面と選択タグを表示する。 | カード本文・条件・並び順・操作・フォーカスを判別でき、画面全体を横に押し広げない。 |
| `MobileDarkEmpty` | 320×568の暗い画面で条件一致0件の案内と解除操作を表示する。 | 0件の理由と解除ボタンを読め、暗い背景でも操作に到達できる。 |
