# DeckListCard

デッキ一覧の1枚分の表示。カード数・学習位置・復習案内と対象デッキへの操作要求を扱う。

Storybook: `Pages/Deck List/DeckListCard`。

[コンポーネント](../../../src/pages/deck-list/ui/DeckListCard.tsx) / [Story](../../../src/pages/deck-list/ui/DeckListCard.stories.tsx) / [一覧・共通前提](../README.md)

## Story仕様

| Story | 入力・表示条件 | 期待する表示・操作 |
| --- | --- | --- |
| `Default` | 通常のデッキとカード数24を渡す。 | 名前、件数と通常の学習操作を表示する。 |
| `WithStudyProgress` | 3枚中の位置0のセッションを渡す。 | 学習中の位置と続きからの操作を表示する。 |
| `TooLongName` | 長いデッキ名を渡す。 | 名前と操作を領域内で確認できる。 |
| `RestoredFromAnotherDevice` | 2枚中の位置1で最終学習日時が不明なセッションを渡す。 | 学習位置を表示し、不明な日時を補って表示しない。 |
| `IphoneX` | モバイル幅で表示する。 | 名前、件数、操作を確認できる。 |
| `Dark` | 暗いテーマで表示する。 | 名前、件数、操作を判別できる。 |
| `Pending` | 対象デッキを処理中にする。 | 対象の操作を無効として表示する。 |
| `DueCards` | 復習12件、新規5件を渡す。 | 受け取った件数と復習に対応する操作を表示する。 |
| `NewCards` | 復習0件、新規18件を渡す。 | 新規学習に対応する案内と操作を表示する。 |
| `NextReview` | 復習・新規とも0で次回日時を渡す。 | 次回の復習に関する案内を確認できる。 |
| `MobileLongName` | 320幅で長いデッキ名を表示する。 | 名前が操作領域を押し出さない。 |
| `NoHeldCards` | カード0枚、復習・新規0件の説明を開く。 | この端末にカードがないことを案内し、学習操作は残す。 |
| `NoMatchingCards` | カードあり、復習・新規0件、次回日時なしで説明を開く。 | 保存した条件に一致しない旨を案内する。 |
| `FutureReview` | カードあり、復習・新規0件、次回日時ありで説明を開く。 | 受け取った次回日時を案内する。 |
| `ReviewRequest` | 復習1件、新規2件で復習を操作する。 | 復習のラベルで対象デッキへの学習要求を通知する。 |
| `NewStudyRequest` | 復習0件、新規2件で新規学習を操作する。 | 新規学習のラベルで対象デッキへの学習要求を通知する。 |
| `StudyWithoutOpening` | 学習ボタンとカード一覧を開く通知先を渡す。 | 学習ボタンは学習だけを要求し、カード一覧を同時に開かない。 |
| `TargetedOperations` | 学習中のデッキで名前・再開・各メニューを操作する。 | それぞれの要求に対象デッキIDを渡す。 |
| `StudyPosition` | 保持カード8枚、学習対象3枚、位置1を渡す。 | 保持数と学習中の2枚目を区別し、進捗率や不要な日時を表示しない。 |
| `UnknownStudyTime` | 2枚中の位置1で最終学習日時が不明。 | 2枚目の位置を表示し、架空の日時を表示しない。 |
| `LocalDeck` | ローカルのデッキを渡す。 | リモートのデッキであることを示す表示を出さない。 |
