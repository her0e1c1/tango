# DeckImportView

ファイル選択、例、解析結果、エラーの表示と操作要求。解析結果は入力として渡し、CSV解析や保存の正しさは扱わない。

Storybook: `Pages/Deck Import/DeckImportView`。

[コンポーネント](../../../src/pages/deck-import/ui/DeckImportView.tsx) / [Story](../../../src/pages/deck-import/ui/DeckImportView.stories.tsx) / [一覧・共通前提](../README.md)

## Story仕様

| Story | 入力・表示条件 | 期待する表示・操作 |
| --- | --- | --- |
| `Default` | 例だけを渡し、ファイルは未選択。 | 追加画面と選択操作を表示し、保存先のラジオ選択を出さない。 |
| `Preview` | 有効2行、空行1行を含む解析結果を渡す。 | カード内容、件数、読み飛ばした行と追加確認を表示する。 |
| `Invalid` | 有効行0、不正1行、列数不足の診断を渡す。 | 行の問題を案内し、追加確認を無効にする。 |
| `PreviewError` | ファイル読込エラーを渡す。 | 安全なプレビュー失敗の案内を表示する。 |
| `Pending` | プレビューありで追加処理中にする。 | 処理中の表示と利用不可の操作を確認できる。 |
| `Validating` | 検証中の状態を渡す。 | プレビュー準備中の状態を表示する。 |
| `MathExample` | 数式の例を初期選択する。 | 数式の例と対応する案内を表示する。 |
| `MarkdownExample` | Markdownの例を初期選択する。 | Markdownの例と対応する案内を表示する。 |
| `SampleDeckExample` | サンプルデッキの例を初期選択する。 | サンプルデッキの例と対応する案内を表示する。 |
| `DarkReview` | 暗いテーマと暗色指定でサンプルデッキの例を表示する。 | 例の本文・選択中の例・ファイル選択と使用操作・フォーカスを暗い背景で判別できる。 |
| `IphoneReview` | モバイル幅でサンプルデッキの例を表示する。 | 例と操作を画面幅内で確認できる。 |
| `JapaneseDiagnostics` | 列数不足の解析結果を日本語で表示する。 | 必要4列に対し3列である旨を日本語で説明し、0枚追加を無効にする。 |
| `FormatDisclosure` | CSV形式の説明を開く。 | 初期は補足を隠し、操作後にヘッダーなし4列の形式を説明する。 |
| `PendingSelection` | プレビューなしで追加処理中にする。 | ファイル選択と例の使用を無効にする。 |
| `ExampleRequests` | Basic・Math・Markdown・Sample deckを順に選ぶ。 | 選択を表示し、使用とダウンロードの要求に例のIDを渡す。 |
| `ExplicitConfirmation` | 有効1行の結果を表示し、選び直しと追加確認を操作する。 | 選び直しでは追加要求を出さず、明示的な追加操作でのみ通知する。 |
| `PartlyInvalid` | 有効行と不正行が混在する解析結果を渡す。 | 不正行の修正を案内し、有効行があっても追加を無効にする。 |
| `SafePreviewFailure` | 内部エラーを渡す。 | 内部の診断文を出さず、ファイルや例を選び直せる。 |
| `AuthenticationFailure` | 認証が必要なエラーを渡して日本語に変える。 | 認証の案内を翻訳する。 |
| `AccountChangedFailure` | アカウント変更のエラーを渡して日本語に変える。 | アカウント変更と再選択の案内を翻訳する。 |
| `PermissionFailure` | 権限不足のエラーを渡して日本語に変える。 | 権限不足の案内を翻訳する。 |
| `NetworkFailure` | 接続不可のエラーを渡して日本語に変える。 | 接続確認と再試行の案内を翻訳する。 |
| `StorageFailure` | ストレージ容量不足を渡して日本語に変える。 | 容量確保の案内を翻訳し、内部診断を表示しない。 |
| `UnknownFailure` | 未知のエラーを渡して日本語に変える。 | 一般的なプレビュー失敗として翻訳し、内部診断を表示しない。 |
| `DiagnosticLanguageChange` | 重複キー・列数・空ファイル・引用符などの診断を日本語に変える。 | ユーザーの入力値を保持し、診断を翻訳して内部情報を隠す。 |
| `ReselectFile` | ファイルを選び、表示されたプレビューから別ファイルを選ぶ。 | 選んだ各ファイルを通知する。解析や保存が実行されたとはみなさない。 |
| `Tablet` | 768×1024の画面で長いファイル名と長文の解析結果を表示する。 | ファイル名・カード本文・件数と確認操作を親幅内で読める。 |
| `Desktop` | 1280×800の画面で例とCSV形式の説明を表示する。 | 例と説明の幅を制限し、例の選択・使用・ダウンロードを識別できる。 |
| `MobileDark` | 320×568の暗い画面で長い名前、プレビュー、不正行の診断を日本語で表示する。 | 本文・診断・無効な追加ボタン・選び直しとフォーカスを読め、横にはみ出さない。 |
| `DarkPending` | 暗いテーマでプレビュー準備中と追加処理中を表示する。 | 進行状態の説明と無効な選択・追加操作を通常状態と区別できる。 |
