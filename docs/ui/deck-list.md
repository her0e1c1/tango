# DeckList

分類済みのデッキ一覧、空状態、復習集計と一覧操作。分類・集計の計算、実際の遷移・データ取得は扱わない。

Storybook: `Pages/Deck List/DeckList`。

[コンポーネント](../../src/pages/deck-list/ui/DeckList.tsx) / [Story](../../src/pages/deck-list/ui/DeckList.stories.tsx) / [一覧・共通前提](./README.md)

## Story仕様

| Story | 入力・表示条件 | 期待する表示・操作 |
| --- | --- | --- |
| `Default` | 学習中とその他のデッキを渡す。 | 渡された区分ごとにデッキと件数を表示する。 |
| `ListActions` | 追加メニューから作成とインポートを選ぶ。 | 対応する要求を通知し、メニューを閉じる。 |
| `Japanese` | 日本語でデッキ一覧を表示する。 | 見出しと追加メニューを日本語で表示し、デッキ名は保持する。 |
| `ViewDeck` | デッキのメニューから閲覧を選ぶ。 | 対象デッキIDで閲覧要求を通知する。 |
| `Inactive` | 学習中なし、その他のデッキだけを渡す。 | 学習中のない一覧を表示する。 |
| `WithStudyProgress` | 学習中のデッキだけを渡す。 | 学習位置と再開操作を持つ一覧を表示する。 |
| `Empty` | 空であることが確認済みの状態を渡す。 | 0件と未作成の案内を表示し、作成・インポートを選べる。 |
| `Checking` | サンプルデッキの確認中を渡す。 | 確認中を表示し、未作成と断定しない。 |
| `BootstrapError` | サンプルデッキの読み込み失敗を渡す。 | エラーと再試行の案内を表示する。 |
| `Long` | 長い名前のデッキを多数渡す。 | 区分と操作を保って一覧を表示する。 |
| `IphoneX` | モバイル幅で通常の一覧を表示する。 | デッキと操作を画面幅内で確認できる。 |
| `Dark` | 暗いテーマで通常の一覧を表示する。 | デッキ、区分、操作を判別できる。 |
| `IphoneXLong` | モバイル幅で長い一覧を表示する。 | 名前と操作が画面幅を押し広げない。 |
| `ReviewCounts` | 学習中・今復習・その他、復習5件・新規5件を渡す。 | 集計値と、端末内データと保存条件に基づく件数である旨を表示する。 |
| `ReviewJapanese` | 復習集計を日本語で表示する。 | 区分と集計の案内を日本語で表示する。 |
| `ReviewMobileDark` | モバイル幅かつ暗いテーマで復習集計を表示する。 | 集計とデッキ操作を確認できる。 |
| `ReviewZoom` | 復習集計の表示を2倍に拡大する。 | 拡大した文字と操作の収まりを確認できる。 |
| `MobileCards` | 日本語かつモバイル幅で復習集計を表示する。 | 日本語のデッキ表示と集計が画面幅に収まる。 |
| `TabletCards` | タブレット幅で復習集計を表示する。 | 広い画面でデッキと集計の配置を確認できる。 |
| `ExclusiveMenus` | 複数デッキのメニューと追加メニューを順に開く。 | 最後に要求したメニューだけを開く。 |
| `KeyboardAddMenu` | Enter・矢印・Escapeで追加メニューを操作し、作成も選ぶ。 | 項目間を移動でき、閉じた後は追加ボタンにフォーカスを戻す。 |
| `CheckingContract` | 確認中の状態を渡す。 | 状態通知で確認中と伝え、未作成の案内を出さない。 |
| `BootstrapRecovery` | 読み込み失敗から再試行・作成・インポートを操作する。 | それぞれの要求を通知する。復旧成功は保証しない。 |
| `OnePendingDeck` | 2件のうち1件だけを処理中にする。 | 処理中のデッキだけを無効にし、もう一方は操作できる。 |
