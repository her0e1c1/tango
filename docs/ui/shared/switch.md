# Switch

オン・オフの表示と変更通知。設定の保存は扱わない。

Storybook: `Shared/Forms/Switch`。

[コンポーネント](../../../src/shared/ui/forms/Switch.tsx) / [Story](../../../src/shared/ui/forms/Switch.stories.tsx) / [一覧・共通前提](../README.md)

## Story仕様

| Story | 入力・表示条件 | 期待する表示・操作 |
| --- | --- | --- |
| `Default` | オフの通常サイズ。 | オフの状態を表示する。 |
| `Interaction` | オフのスイッチをクリックする。 | オンの表示に変わり、変更を公開callbackへ通知する。 |
| `Checked` | オンの値を渡す。 | オンの状態を表示する。 |
| `Disabled` | オンのまま無効にする。 | オンの表示を保ち、利用者が変更できない。 |
| `Small` | 小さいサイズで表示する。 | 通常より小さいスイッチを表示する。 |
| `Large` | 大きいサイズで表示する。 | 通常より大きいスイッチを表示する。 |
| `LightAndDark` | 明暗それぞれの背景にオンとオフを並べる。 | 両方の背景でオン・オフを区別できる。 |
| `NarrowViewport` | 狭いモバイル画面にオンのスイッチを置く。 | スイッチが画面幅に収まり、状態を判別できる。 |
| [TODO] `Tablet` | 768×1024の画面で小・通常・大のオンとオフを並べる。 | 各サイズのつまみと選択状態を確認でき、隣の操作に重ならない。 |
| [TODO] `Desktop` | 1280×800の画面でオン・オフ・無効を並べる。 | 広い画面でも部品のサイズを保ち、有効なスイッチをキーボードで切り替えられる。 |
