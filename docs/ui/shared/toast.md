# ToastViewport

通知UIの表示仕様。既存Storyは showToast で通知を準備し、自動消去を止めているため、本番の消去時間を保証する例ではない。

Storybook: `Shared/Feedback/Toast`。

[コンポーネント](../../../src/shared/ui/toast/Toast.tsx) / [Story](../../../src/shared/ui/toast/Toast.stories.tsx) / [一覧・共通前提](../README.md)

## Story仕様

| Story | 入力・表示条件 | 期待する表示・操作 |
| --- | --- | --- |
| `Neutral` | 通常の通知としてサインイン成功の文言を表示する。 | 通常の通知の外観と閉じる操作を確認できる。 |
| `Success` | 成功の通知として同じ文言を表示する。 | 成功の種別を外観から判別できる。 |
| `Warning` | フィルター保存失敗を警告として表示する。 | 警告の外観とメッセージを確認できる。 |
| `ErrorState` | 保存失敗をエラーとして表示する。 | エラーの外観とメッセージを確認できる。 |
| `LongMessage` | ストレージに関する長いエラー文を表示する。 | 文言が通知領域内に収まって読める。 |
| `LongCardCreated` | 狭い画面で非常に長いカード名を含む成功通知を表示する。 | 長い名前が通知の操作や画面幅を壊さない。 |
| `LongCardCreatedJapanese` | 同じ長いカード名の通知を日本語にする。 | 日本語の文章と差し込んだ名前を確認できる。 |
| `NonInteractive` | 閉じる操作のないスワイプ通知を表示する。 | 通知内容を表示し、閉じるボタンを表示しない。 |
| `DirectionIcon` | 同じ通知に右向きアイコンを渡す。 | 視覚的な方向を表示し、読み上げ用の通知文を保つ。 |
| `Dark` | 暗いテーマで成功通知を表示する。 | 通知面・内容・成功の種別・閉じる操作を暗い背景から判別できる。 |
| `WithParameters` | インポート件数3を通知文に渡す。 | 件数が差し込まれたメッセージを表示する。 |
| `Tablet` | 768×1024の画面で長い名前を含む通知を表示する。 | 通知が表示領域に収まり、閉じる操作を隠さない。 |
| `Desktop` | 1280×800の画面で通常・成功・警告・エラーの通知を順に表示する。 | 通知の幅が広がりすぎず、メッセージと種別を読める。 |
| `MobileDark` | 320×568の暗い画面で長い日本語の通知を各種別で表示する。 | 種別・本文・閉じる操作・フォーカスを判別でき、通知が横にはみ出さない。 |
| `Landscape` | 812×375の画面で長い通知を表示する。 | 低い高さでも通知文と閉じる操作に到達できる。 |
