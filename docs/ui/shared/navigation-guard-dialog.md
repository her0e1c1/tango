# NavigationGuardDialog

未保存の変更を破棄するか編集を続けるかの確認表示。実際の離脱制御は扱わない。

Storybook: `Shared/Router/NavigationGuardDialog`。

[コンポーネント](../../../src/shared/ui/navigation-guard-dialog/NavigationGuardDialog.tsx) / [Story](../../../src/shared/ui/navigation-guard-dialog/NavigationGuardDialog.stories.tsx) / [一覧・共通前提](../README.md)

## Story仕様

| Story | 入力・表示条件 | 期待する表示・操作 |
| --- | --- | --- |
| `Default` | 変更の破棄と編集継続の通知先を渡す。 | 未保存の変更に関する警告と、破棄・編集継続の選択肢を表示する。 |
| `Pending` | 処理中の状態を渡す。 | 破棄操作を無効にして処理中の説明を表示する。編集継続は操作できる。 |
| `Mobile` | 320×568の明るい画面で長い変更破棄の説明を表示する。 | 説明を折り返し、破棄と編集継続の両方を画面内で操作できる。 |
| `Tablet` | 768×1024の画面で通常の変更破棄確認を表示する。 | 対話領域の余白を保ち、警告と選択肢が重ならない。 |
| `Desktop` | 1280×800の画面で通常の変更破棄確認を表示する。 | ダイアログが広がりすぎず、編集継続への初期フォーカスを確認できる。 |
| `Dark` | 暗いテーマで通常と処理中の状態を切り替える。 | 警告・破棄・編集継続・フォーカスを区別でき、処理中は破棄だけが無効になる。 |
| `MobileDark` | 320×568の暗い画面で長い説明を表示する。 | 警告と両方の選択肢を読め、フォーカスが見え、操作が横にはみ出さない。 |
| `Landscape` | 812×375の画面で長い説明を表示する。 | 低い高さでも説明の末尾と両方の選択肢に到達できる。 |
