# Logo

ロゴの文字付き・マークのみの表示。

Storybook: `Shared/Content/Logo`。

[コンポーネント](../../../src/shared/ui/logo/Logo.tsx) / [Story](../../../src/shared/ui/logo/Logo.stories.tsx) / [一覧・共通前提](../README.md)

## Story仕様

| Story | 入力・表示条件 | 期待する表示・操作 |
| --- | --- | --- |
| `Wordmark` | 明るいテーマで通常表示する。 | 文字付きのロゴを表示する。 |
| `MarkOnly` | 明るいテーマでマークのみを指定する。 | 文字部分を伴わないマークを表示する。 |
| `Light` | 明るいテーマの通常表示。 | 明るい背景でロゴを判別できる。 |
| `Dark` | 暗いテーマの通常表示。 | 暗い背景でマークと文字を判別できる。 |
| `Mobile` | 320×568の明るい画面で文字付きとマークのみを並べる。 | どちらのロゴも欠けず、縦横比を保って画面幅内に収まる。 |
| `Tablet` | 768×1024の画面で文字付きとマークのみを表示する。 | 画面が広くなってもロゴが不自然に引き伸ばされない。 |
| `Desktop` | 1280×800の画面で文字付きとマークのみを表示する。 | マークと文字の比率を保ち、指定した領域内に収まる。 |
| `MobileDark` | 320×568の暗い画面で文字付きとマークのみを並べる。 | マークと文字が暗い背景に埋もれず、輪郭が欠けない。 |
