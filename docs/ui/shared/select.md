# Select

選択肢と選択状態の表示。選択値を利用した業務処理は扱わない。

Storybook: `Shared/Forms/Select`。

[コンポーネント](../../../src/shared/ui/forms/Select.tsx) / [Story](../../../src/shared/ui/forms/Select.stories.tsx) / [一覧・共通前提](../README.md)

## Story仕様

| Story | 入力・表示条件 | 期待する表示・操作 |
| --- | --- | --- |
| `Default` | 選択肢を渡した通常の選択欄。 | 選択肢を選び、選択したラベルを表示できる。 |
| `Empty` | 空の選択肢を有効にする。 | 通常の選択肢に加えて未選択の状態を表せる。 |
| `Invalid` | 空の選択肢を有効にし、必須かつ未選択にする。 | 必須の未選択状態を再現する。独自のエラーメッセージは前提にしない。 |
| `States` | 通常、空の選択肢あり、無効の選択欄を並べる。 | 各状態の違いを比較でき、無効の欄では選択を変更できない。 |
| `LongValue` | 長いラベルの選択肢を選択済みにする。 | 選択欄の幅を保ったまま長いラベルを表示する。 |
| `LightAndDark` | 明暗それぞれの背景に選択欄を置く。 | 両方の背景で選択値とコントロールを判別できる。 |
| `NarrowViewport` | 狭いモバイル画面で長い選択肢を表示する。 | 選択欄が画面幅に収まる。 |
