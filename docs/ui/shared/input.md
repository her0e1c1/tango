# Input

単一行入力の値・属性・表示。アプリ固有の入力検証は扱わない。

Storybook: `Shared/Forms/Input`。

[コンポーネント](../../../src/shared/ui/forms/Input.tsx) / [Story](../../../src/shared/ui/forms/Input.stories.tsx) / [一覧・共通前提](../README.md)

## Story仕様

| Story | 入力・表示条件 | 期待する表示・操作 |
| --- | --- | --- |
| `Default` | 初期値のある通常の入力欄。 | 初期値を表示し、入力を編集できる。 |
| `States` | placeholder、読み取り専用、無効の入力欄を並べる。 | 空欄では補助表示が見え、読み取り専用と無効の欄では値を編集できない。 |
| `Invalid` | 必須の入力欄を空にする。 | 必須の空欄状態を再現する。独自のエラーメッセージは前提にしない。 |
| `LongValue` | 表示幅を超える長い単一行の初期値。 | 値を保持し、入力欄自体が内容によって横に広がらない。 |
| `LightAndDark` | 明暗それぞれの背景で値を表示する。 | 両方の背景で値と入力欄を判別できる。 |
| `NarrowViewport` | 狭いモバイル画面に長めの値を表示する。 | 入力欄が画面幅に収まり、値を編集できる。 |
| [TODO] `Tablet` | 768×1024の画面で長い値の入力欄を幅の狭い親領域に置く。 | 親領域を押し広げず、欄内で値の末尾へ移動して編集できる。 |
| [TODO] `Desktop` | 1280×800の画面で通常・読み取り専用・無効の欄を表示する。 | 各欄の値と操作可否が分かり、広い画面でも指定した入力幅を保つ。 |
