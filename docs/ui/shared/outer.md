# Outer

外側の背景と標準ページのスクロール領域。

Storybook: `Shared/Layout/Outer`。

[コンポーネント](../../../src/shared/ui/outer/Outer.tsx) / [Story](../../../src/shared/ui/outer/Outer.stories.tsx) / [一覧・共通前提](../README.md)

## Story仕様

| Story | 入力・表示条件 | 期待する表示・操作 |
| --- | --- | --- |
| `Default` | 明るいテーマで一つのセクションを置く。 | アプリの背景上にセクションを表示する。 |
| `MobileDarkLongContent` | 暗いモバイル画面に8つのセクションを置く。 | 本文と背景を判別でき、縦にスクロールして全セクションを確認できる。 |
| `Mobile` | 320×568の明るい画面に高さを超える複数のセクションを置く。 | 縦スクロールで末尾へ到達でき、画面全体に不要な横スクロールを生まない。 |
| `Tablet` | 768×1024の画面に長い本文を置く。 | 外側の背景が途中で途切れず、内容の末尾までスクロールできる。 |
| `Desktop` | 1280×800の画面に短い内容と長い内容を置く。 | 内容が短くても背景が表示領域を覆い、長ければ縦に読み進められる。 |
| `MobileDark` | 320×568の暗い画面に長い本文を置く。 | スクロール後も暗い背景と読める本文を保ち、下端に意図しない明るい帯を出さない。 |
