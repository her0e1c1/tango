# Style

子コンテンツの文字組みとクリック通知。クリック後の業務処理は扱わない。

Storybook: `Shared/Content/Style`。

[コンポーネント](../../../src/shared/ui/content/Style.tsx) / [Story](../../../src/shared/ui/content/Style.stories.tsx) / [一覧・共通前提](../README.md)

## Story仕様

| Story | 入力・表示条件 | 期待する表示・操作 |
| --- | --- | --- |
| `Inline` | 通常の短い本文を渡す。 | インラインの本文として表示する。 |
| `Block` | 強調を含む子要素をブロック表示にする。 | 強調と自然な折り返しを保って表示する。 |
| `LongContent` | 長い未分割文字列を含む本文をブロック表示にする。 | 内容が表示領域を横に押し広げない。 |
| `Interaction` | クリック通知先を渡した本文をクリックする。 | 公開callbackへクリックを通知する。 |
| `Mobile` | 長い本文を狭いモバイル画面に表示する。 | 画面幅内で本文を確認できる。 |
| `Dark` | 強調を含むブロックを暗いテーマにする。 | 暗い背景でも本文と強調を判別できる。 |

| [TODO] `Desktop` | 1280×800の画面でインラインとブロックの本文を表示する。 | 各表示形式と強調を保ち、渡した文章の内容を欠落させない。 |
