# Main

主コンテンツ領域の幅・余白・背景。画面固有の内容は扱わない。

Storybook: `Shared/Layout/Main`。

[コンポーネント](../../../src/shared/ui/main/Main.tsx) / [Story](../../../src/shared/ui/main/Main.stories.tsx) / [一覧・共通前提](../README.md)

## Story仕様

| Story | 入力・表示条件 | 期待する表示・操作 |
| --- | --- | --- |
| `Default` | 明るいテーマで見出しと本文を置く。 | 内容を読みやすい幅と余白のある主領域に表示する。 |
| `NarrowDarkReadingSurface` | 暗いモバイル画面に4つの読み取りセクションを置く。 | セクションの間隔を保ち、本文と背景を判別でき、本文を画面幅内で読める。 |
| `Canvas` | 通常の内容をcanvasの背景にする。 | 内容の配置を保ちつつ、canvasの背景で表示する。 |
| `Mobile` | 320×568の明るい画面で長い見出しと本文を表示する。 | 左右の余白を保ち、内容が画面幅を押し広げない。 |
| `Tablet` | 768×1024の画面で複数の長いセクションを表示する。 | 主領域の余白とセクション間隔を保ち、本文を読める。 |
| `Desktop` | 1280×800の画面で長い本文を表示する。 | 本文が画面いっぱいに伸びず、幅を制限した主領域と左右の余白を保つ。 |
| `MobileDark` | 320×568の暗い画面で長い見出しと本文を通常面・canvas面に表示する。 | 各背景で文字を読め、見出しと本文が画面幅内に収まる。 |
