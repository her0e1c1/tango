# Textarea

複数行入力の値・属性・表示。アプリ固有の入力検証は扱わない。

Storybook: `Shared/Forms/Textarea`。

[コンポーネント](../../../src/shared/ui/forms/Textarea.tsx) / [Story](../../../src/shared/ui/forms/Textarea.stories.tsx) / [一覧・共通前提](../README.md)

## Story仕様

| Story | 入力・表示条件 | 期待する表示・操作 |
| --- | --- | --- |
| `Default` | 空の入力欄を4行分の高さで表示する。 | 複数行の文字を入力できる。 |
| `Invalid` | 必須の入力欄を空にする。 | 必須の空欄状態を再現する。独自のエラーメッセージは前提にしない。 |
| `States` | placeholder、読み取り専用、無効の欄を並べる。 | 空欄では補助表示が見え、読み取り専用と無効の欄では値を編集できない。 |
| `LongValue` | 長文を初期値にする。 | 長文が入力欄内で折り返され、内容を確認できる。 |
| `LightAndDark` | 明暗それぞれの背景に入力済みの欄を置く。 | 両方の背景で本文と入力欄を判別できる。 |
| `NarrowViewport` | 狭いモバイル画面に長文を表示する。 | 画面幅に収まり、複数行の値を読んで編集できる。 |
| [TODO] `Tablet` | 768×1024の画面で改行を含む長文を幅の狭い親領域に置く。 | 入力欄が親幅に収まり、折り返しと改行を保って末尾を編集できる。 |
| [TODO] `Desktop` | 1280×800の画面で長文を入力し、入力欄内をスクロールする。 | 欄の外に本文があふれず、先頭から末尾まで値を読んで編集できる。 |
