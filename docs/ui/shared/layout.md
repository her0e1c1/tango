# Layout

ヘッダーと主領域を組み合わせた汎用レイアウト。Appの認証・ルーティングは扱わない。

Storybook: `Shared/Layout/Layout`。

[コンポーネント](../../../src/shared/ui/layout/Layout.tsx) / [Story](../../../src/shared/ui/layout/Layout.stories.tsx) / [一覧・共通前提](../README.md)

## Story仕様

| Story | 入力・表示条件 | 期待する表示・操作 |
| --- | --- | --- |
| `Default` | 明るいテーマでヘッダーと短い本文を表示する。 | ヘッダー、幅を制限した本文領域、下部余白を表示する。 |
| `FixedHeaderLongContent` | 固定ヘッダーと8つのセクションを表示して下へスクロールする。 | 先頭内容がヘッダーに隠れず、スクロールしてもヘッダーの位置を保つ。 |
| `MobileDarkFullscreen` | 暗いモバイル画面で全画面・スクロール可にし、6つのセクションを表示する。 | ヘッダーと本文の配色をそろえ、全画面の領域内で縦にスクロールして内容を確認できる。 |
| `Mobile` | 320×568の明るい画面で固定ヘッダーと長い本文を表示する。 | 先頭の本文がヘッダーに隠れず、末尾まで縦にスクロールできる。 |
| `Tablet` | 768×1024の画面でヘッダーと複数のセクションを表示する。 | 主領域の幅・余白とヘッダーの配置を保ち、本文が重ならない。 |
| `Desktop` | 1280×800の画面で固定ヘッダーと長い本文を表示する。 | 本文の幅を制限し、スクロールしてもヘッダーが同じ位置に残る。 |
| `MobileDark` | 320×568の暗い画面で通常レイアウトの固定ヘッダーと長い本文を表示する。 | ヘッダー・本文・背景の暗色表示を保ち、内容が隠れず末尾まで読める。 |
| `Landscape` | 812×375の画面で固定ヘッダーと長い本文を表示する。 | 低い高さでも本文領域を確保し、スクロールで内容と操作に到達できる。 |
