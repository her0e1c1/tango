# FormItem

項目ラベル・補足・エラー・子コントロールの配置。入力検証そのものは扱わない。

Storybook: `Shared/Forms/FormItem`。

[コンポーネント](../../../src/shared/ui/forms/FormItem.tsx) / [Story](../../../src/shared/ui/forms/FormItem.stories.tsx) / [一覧・共通前提](../README.md)

## Story仕様

| Story | 入力・表示条件 | 期待する表示・操作 |
| --- | --- | --- |
| `Default` | 項目ラベル、補足説明、読み取り用の値を渡す。 | ラベル・補足・値を区別して表示する。 |
| `HelpAndError` | 空の入力欄にラベル、補足、エラー文を関連付け、縦配置にする。 | 補足とエラーを同時に表示し、ラベルから入力欄を識別できる。 |
| `LongLabelAndValue` | 長いラベルと長い読み取り用の値。 | 内容が折り返され、項目が表示幅を押し広げない。 |
| `ItemSwitch` | 子要素としてラベルと関連付けたスイッチを置く。 | ラベルとスイッチを一つの項目として表示する。 |
| `ItemSelect` | 子要素としてラベルと関連付けた選択欄を置く。 | ラベルと選択欄を一つの項目として表示する。 |
| `ItemButton` | 子要素として Login ボタンを置く。 | ラベル・補足とボタンを配置する。 |
| `ItemSlider` | 子要素としてラベルと関連付けたスライダーを置く。 | ラベルとスライダーを一つの項目として表示する。 |
| `ItemInput` | 子要素としてラベルと関連付けた入力欄を置く。 | ラベルと入力値を表示する。 |
| `LightAndDark` | 明暗それぞれの背景で補足を表示し、暗い背景ではエラーも渡す。 | ラベル・値・補足・エラーの違いを判別できる。 |
| `NarrowMobile` | 狭いモバイル画面で長いラベル、補足、入力欄を縦配置にする。 | ラベルが折り返され、入力欄が画面幅に収まる。 |
