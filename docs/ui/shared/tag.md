# Tag

選択用タグの表示と変更通知。タグ条件の適用・保存は扱わない。

Storybook: `Shared/Forms/Tag`。

[コンポーネント](../../../src/shared/ui/forms/Tag.tsx) / [Story](../../../src/shared/ui/forms/Tag.stories.tsx) / [一覧・共通前提](../README.md)

## Story仕様

| Story | 入力・表示条件 | 期待する表示・操作 |
| --- | --- | --- |
| `Default` | 通常サイズの未選択タグ。 | ラベルと未選択状態を表示する。 |
| `Small` | 小さいサイズ。 | 小さいタグとしてラベルを表示する。 |
| `Large` | 大きいサイズ。 | 大きいタグとしてラベルを表示する。 |
| `Checked` | 選択済み。 | 未選択と区別できる選択済み表示になる。 |
| `Disabled` | 選択済みのまま無効にする。 | 選択状態を保ち、操作できない状態を表示する。 |
| `Clickable` | 未選択タグに変更通知先を渡す。 | 利用者の操作を公開callbackへ通知できる。選択値の反映は呼び出し側が担う。 |
| `ClickableChecked` | 選択済みタグに変更通知先を渡す。 | 選択済み表示からの操作を公開callbackへ通知できる。 |
| `LongLabel` | 幅を制限した領域に長いラベルを置く。 | タグが領域を横に押し広げず、ラベルの表示を確認できる。 |
| `LightAndDark` | 明暗それぞれの背景に未選択と選択済みを並べる。 | 両方の背景で選択状態を区別できる。 |
| `NarrowViewport` | 狭いモバイル画面に丸い選択済みタグを置く。 | ラベルと選択状態を判別でき、画面幅に収まる。 |
