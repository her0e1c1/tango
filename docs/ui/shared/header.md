## Story仕様

| Story | 入力・表示条件 | 期待する表示・操作 |
| --- | --- | --- |
| `Default` | 明るいテーマの通常ヘッダー。 | ヘッダーの内容を表示する。 |
| `MobileDarkFixed` | 暗いモバイル画面で固定ヘッダーにする。 | ロゴ・リンク・フォーカスが見える暗色のヘッダーを固定配置で表示する。 |
| `Mobile` | より狭いモバイル画面に表示する。 | ヘッダーの内容が画面幅に収まる。 |

| [TODO] `Desktop` | 1280×800の画面で通常のヘッダーを表示する。 | ロゴと各操作を識別でき、操作順とフォーカス表示を保つ。 |
| [TODO] `MobileDark` | 320×568の暗い画面で固定しない暗色ヘッダーを表示する。 | ロゴ・リンク・フォーカスを判別でき、各操作が横にはみ出さない。 |
