# Prefer Standard Tooling

Status: Accepted

## Context

Maintaining custom scripts, wrappers, and private-implementation checks is costly and violates `Be simple.` Standard tools already own many of the contracts that custom code attempts to duplicate.

## Decision

Unless explicitly directed otherwise, prefer official APIs, standard commands, and normal build integrations provided by TypeScript, Vite, Firebase, React Router, Biome, and similar tools.

Do not maintain thin wrappers that only rename a standard API, custom verifiers for artifacts already generated by the owning tool, or checks that depend on private implementation details. Add custom tooling only when the standard tool cannot express a required project contract, and document that gap.

Use standard `tsc` and Biome commands instead of a dedicated TypeScript coverage script. Rely on the normal Vite PWA build instead of inspecting Workbox output, Firebase public persistence APIs instead of private runtime inspection, and React Router hooks instead of a pass-through navigation facade. See [PR #452](https://github.com/her0e1c1/tango/pull/452), [PR #777](https://github.com/her0e1c1/tango/pull/777), and [PR #1213](https://github.com/her0e1c1/tango/pull/1213).
