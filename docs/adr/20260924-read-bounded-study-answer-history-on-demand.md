# 回答履歴は範囲を絞って取得し、不完全さも返す

Status: Accepted

## Decision

StudyAnswer の履歴は、所有者・期間・任意の Deck・件数上限を指定する一回の読み取りにする。Entity API が取得し、Page が要求と結果を管理する。全回答の常時購読やグローバル Store への蓄積は行わない。

- レコードとともに、キャッシュ / サーバーの取得元、上限による切り詰め、不正ドキュメント数、未同期書き込みの有無を返す。不完全な履歴を完全な集計として扱わない。
- 不正ドキュメントは件数を報告してこの取得結果から除外する。[購読コレクションを全体検証する方針](./20260830-use-firestore-subscriptions-as-remote-state-source.md)とは別の、範囲を限定した読み取り契約とする。
- UID・条件・再試行が変わった後の古い応答は反映しない。回答の取得失敗で Session の集計まで使えなくしない。
- 回答の集計は純粋な処理にし、回答ゼロの正答率は 0% ではなく未定義として扱う。

## Context

増え続ける回答を常時保持する必要はなく、期間と件数を限定すれば読み取り量を抑えられる。一方、キャッシュや上限で欠けた結果から、完全な学習実績であるかのように数値を出してはいけない。
