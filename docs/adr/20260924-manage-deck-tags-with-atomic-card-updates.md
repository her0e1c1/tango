# Deck の登録タグと Card のタグ変更を一括保存する

Status: Accepted

## Decision

登録タグは Deck に名前の集合として保存し、Card への付与がなくても保持する。独立した Tag Entity は作らず、管理一覧には既存 Card だけが持つタグも重複なく含める。

- 管理 UI は Deck 編集画面内に置き、Deck 本体の編集・保存とは独立した操作にする。
- 改名・削除は Deck の登録タグと対象 Card のタグを同じ batch で更新する。Card 本文、他のタグ、他の Deck は変更せず、保存済みの閲覧・学習フィルターへの伝播はこの操作に含めない。
- Deck 編集 Page が処理を組み立て、Deck・Card の各 API が自身の保存を担う。タグ更新は未同期の Card 作成・編集も含むキャッシュから組み立て、先行する書き込みと同じ SDK キューに続ける。
- 対象は必要な Deck・Card を読み込み済みの単一タブとする。未取得・消失したキャッシュや別端末での同時編集まで整合させる処理は持たず、batch の要求サイズ・Rules の制限も残る。

## Context

Card のタグだけを集計すると、未使用のタグを登録・保持できない。改名・削除を個別保存すると途中状態が残り、未同期の編集を無視すると古いタグが戻り得るため、登録情報と対象 Card をまとめて更新する。
