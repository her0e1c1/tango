# Deck の登録タグを Card への付与と独立して管理する

Status: Accepted

## Decision

タグは Deck 単位で登録し、Card に使われていなくても保持する。管理は Deck 編集画面内で行い、Deck 本体の編集内容の保存・破棄とは独立させる。

- 登録タグと既存 Card のタグを重複なく表示する。タグのためだけの独立 Entity や専用管理ページは作らない。
- 名前変更・削除は、Deck の登録タグと対象 Card の付与タグを一つのバッチで更新する。Card 本体・他のタグ・他の Deck は変更しない。
- 各 Entity API は自身の保存処理を持ち、Deck 編集 Page が複数 Entity の操作を組み合わせる。
- オフラインと匿名利用も既存のローカル反映契約に従う。保留中の Card 作成・編集を含むキャッシュを読み、同じ SDK の書き込み順序を使う。連携済みアカウントは再接続後に同期し、匿名の変更はローカルに留める。

## Context

Card からタグ候補を導くだけでは、未使用タグを登録・保持できない。登録と付与を区別し、名前変更や削除では両方をまとめて変更する。

対象は必要な Deck / Card キャッシュを読み込み済みの単一タブでの操作とする。不完全なキャッシュ、端末間の同時編集、Firestore のリクエストサイズや Rules の制限を解消するものではない。Card 編集で登録タグを選ぶ機能や、保存済みフィルターへの名前変更の伝播まで実装済みとは扱わない。
