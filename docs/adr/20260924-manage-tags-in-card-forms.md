# タグを Card フォームで管理する

Status: Accepted

## Context

`deck.tags` と `card.tags` にタグを重複して管理すると、候補と付与状態の同期が必要になる。タグを使用する Card を唯一の保存元とし、未使用の登録タグを保持する仕組みを廃止する。

## Decision

`deck.tags` は不要とし、Deck のモデルと Firestore ドキュメントへの新規書き込みに含めない。タグは `card.tags` だけに保存する。

- Card 作成・編集フォームで追加・名前変更・解除を行う。確認やタグ単位の OK・保存操作は設けず、フォームの下書きへ即時反映する。永続化は Card 全体の保存時に本文とまとめて行う。
- 名前変更・解除の対象は編集中の Card のみとする。他の Card のタグは変更しない。
- フォームとフィルターの候補は同じ Deck の有効な Card のタグ集合から導き、独立した登録一覧を保存しない。最後の割り当てがなくなったタグは候補から消える。
- 閲覧・学習の選択条件は引き続き独立して保存する。候補から消えた選択済みタグも解除できるようにする。
- 既存の `deck.tags` は参照せず、一括削除・移行処理は追加しない。

[Deck の登録タグを独立管理する方針](./20260924-manage-deck-tags-independently-of-card-assignments.md)を置き換える。
